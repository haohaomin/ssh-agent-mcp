## 发现并修复的问题

1. **原生转发通道销毁未终止 SSH 子进程。** 为原生进程通道补充销毁处理，并处理 stdin 错误；回归测试确认关闭后子进程退出。
2. **终端自然退出后重开同名会话遗留旧 worker。** 重开前先停止旧 worker；测试确认新会话使用新 PID、原 PID 退出。
3. **SSH 断线时反向转发清理抛出 `Not connected`。** 清理允许连接已关闭的情况，并移除转发的 close 监听器，避免重复启停积累监听器；真实断线测试通过。

4. **autoClose 退出时观察窗口遗留。** worker 退出前读取包含观察窗口信息的最新元数据，关闭对应 tmux 会话并标记终端已关闭；两种后端的真实窗口回归通过。

终端 worker 的 IPC 通道同时使用 UTF-8 流式解码，避免 socket 分包时直接转字符串破坏中文字符。

## 实测覆盖

`test/mcp-live-tools.test.js` 使用真实 MCP stdio 客户端及临时 sshd，分别在 ssh2 / OpenSSH 上验证：

- 服务器列表、命令工作目录与环境变量、中文输出、非零退出码、超时及超时后继续执行。
- 文件独占创建、追加、按字节与按行读取、精确编辑、目录浏览、正则计数与 glob 查找。
- 二进制嵌套目录上传下载及逐字节一致性。
- rsync 预览、实际同步、目标删除、带空格路径，以及 SFTP 同步。
- 受限路径访问返回错误。
- 终端新建、复用、列表、输入、输出、停止与停止后的日志读取。
- 后台任务启动、环境变量、完成状态与退出码、列表、停止。
- 双向转发实际 TCP 数据往返、列表与停止。
- 连接诊断、JSON 配置热加载及保留路径限制、重连后执行，以及会话日志清理 dry-run。

其他实际网络及回归测试覆盖：

- 仅允许证书的认证、加密私钥、错误服务器公钥拒绝。
- ProxyCommand、Match exec 在连接时执行；导入时不执行。
- rsync 大文件小修改产生块级匹配数据。
- 原 MCP 父进程退出后，新的进程复用同一终端且保留环境。
- 文件原子编辑失败保留原文件、符号链接与路径校验、搜索截断与排除、病态正则超时恢复。
- 连接管理、认证/代理逻辑、HTTP 鉴权与生命周期、CLI 导入和参数校验。
- 热加载保留未变化的真实连接；旧连接的延迟 close 不清掉新连接；非法配置原子回退；OpenSSH 主机选择与 CLI 策略保留。
- 诊断成功/失败均不返回配置中的凭据；日志按年龄与空间清理、默认预览、跳过存活 worker、锁和异常路径。

本轮共新增 6 项维护工具回归，并将两种后端的全工具测试扩展至 29 个工具。停止终端的响应现在在元数据写入和 worker 清理后发送，避免调用方收到成功后临时目录仍被写入。

## 范围说明

测试使用自动生成的临时密钥、仅监听 loopback 的临时 SSH 服务和临时文件。新增后台任务集成测试将远端 HOME 指向临时目录；未连接用户的真实服务器。

已通过 Homebrew 安装 tmux 3.8，并在隔离的 tmux server 中实测观察窗口（使用 capture-pane 验证实际中文显示）、窗口复用及手动/自动关闭。测试不使用个人 tmux 配置或已有会话。未实测 Windows、全部远端操作系统和生产堡垒机组合，也未做吞吐压力基准。认证/代理的部分组合由模拟测试覆盖，不能解读为每种组合均已通过真实网络验证。

tmux 观察集成测试还需要本机安装 `tmux`；macOS 可使用 `brew install tmux`。
